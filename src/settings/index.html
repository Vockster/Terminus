    Install

    Install it

    Follow these five steps once. Paste each copied address into Firefox's address bar.

    1. 1Open your profile folderAt about:support, choose Open Folder beside Profile Folder (Show in Finder on a Mac).
    2. 2Add the fileCreate a folder called chrome and move the userChrome.css file into the chrome folder.
    3. 3Open advanced settingsGo to about:config and accept the warning Firefox shows.
    4. 4Allow custom stylesSearch for toolkit.legacyUserProfileCustomizations.stylesheets and set it to true.
    5. 5Restart FirefoxQuit completely and reopen it. Closing the window isn't enough.

    Undo

    How to undo

    If userChrome.css contains only Terminus, delete it; otherwise remove only the Terminus block. Then quit and reopen Firefox. The preference can stay on.

    Troubleshooting

    Header still there?

    Wrong profile
    Use the folder about:support opens in the Firefox you're using.
    Wrong name
    It must be chrome/userChrome.css exactly, not userChrome(1).css or userChrome.css.txt.
    Preference off
    The preference in step 4 must read true.
    Not restarted
    Firefox reads the file only at startup. Quit it completely.
    After an update
    Firefox can rename the header, and Terminus updates never replace your copy. Download again and replace only the Terminus rule (or the whole file when it contains nothing else).

    Basics

    Quick moves

    Most of Terminus works with four mouse actions.

    Click a workspace
    Switch to it. Other workspaces' tabs are hidden, never closed.
    Right-click anything
    Open every action for that tab, group, or workspace.
    Middle-click
    Unload a tab, a group or a whole workspace to free memory.
    Drag a workspace
    Move it on the rail.

    Features

    What Terminus does

    Workspaces

    • Each holds the tabs for one part of your day.
    • Export layouts and custom icons without including tabs.
    • Removing a workspace moves its tabs instead of closing them.

    Snapshots

    • Saves workspaces, tabs, groups, and window layouts.
    • Manual saves stay until you delete them.
    • Restored tabs stay unloaded until selected.

    Appearance

    • Follow Firefox, or set a color or gradient.
    • Four sizes for workspaces and tabs.
    • Full labels or icons only.
